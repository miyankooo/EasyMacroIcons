# Macro Icon ID

A WoW Forever addon that sets any macro's icon from an icon ID, including icons the macro window's own picker does not list.

## Features

- Right-click a macro in the macro window to set its icon.
- Shows the new icon beside the macro name while you type.
- Tells you when the game does not accept an icon ID.

## Usage

1. Open the macro window with `/macro`.
2. Right-click a macro.
3. Type the icon ID, for example from Wowhead's WoW Forever icon pages.
4. Press Enter or click Okay.
