# Easy Macro Icons

Give any macro any icon by its ID, even icons the macro window's own picker doesn't list.

- **Right-click** a macro in the macro window
- **Type** an icon ID or paste a Wowhead icon link
- **Copy and paste** icons between macros

## Why use it

- **Every icon, not just the picker's.** Any icon ID the game accepts.
- **Straight from Wowhead.** Paste a whole icon link and the ID is read from it.
- **Reuse an icon in two clicks.** Copy Icon on one macro, Paste Icon on another.

## Features

- Right-click menu: Set Icon, Copy Icon, Paste Icon and Wowhead Link
- Wowhead Link shows the WoW Forever icon library's link already selected, so one keypress copies it
- Type part of an icon ID to filter every icon the macro window offers, then click one
- See the new icon beside the macro name before you set it
- Tells you when the game doesn't accept an icon ID

## Quick start

1. Open the macro window with `/macro`
2. Right-click a macro and pick Wowhead Link. Copy it with Cmd+C on macOS or Ctrl+C on Windows and open it in your browser
3. Open an icon there. Its ID is the number after `icon=` in the address
4. Right-click the macro again, pick **Set Icon**, type the ID or paste the link, and press Enter

## Commands

`/emi intro` and `/emi help`
